# 我的部分——DIOS 信号与地点核查

## 数据
组委会入口 https://unfpa-looker-web-app-126183358624.us-east1.run.app/dashboard 。用户于 2026-11-03 导出两份 CSV，原文件在 public/data/sources/dios。共 1,330 行，其中 1 行无文章编号。按 Article ID 合并为 550 篇，国家字段 Nigeria 对应 262 篇。

同一文章的不同主题及地点线索合并保存，同时保留原始行数和来源文件名。这是文章编号去重，仍需人工判断多篇文章是否描述同一事件。原始导出缺少经纬度和发表日期，不用文件名中的导出时间代替事件日期。

字段包括文章编号、标题、原文链接、主题、国家、情绪/关注分类、分类解释、摘要、发布网站、模型名称和行政区线索。情绪分类保持原始语义。

## 已完成
真实文章浏览、主题筛选、标题/摘要搜索、原文跳转。支持确认、拒绝、重复事件、国家或地点冲突等审核记录。记录审核人、说明和时间，保存在本浏览器 localStorage，可导出 JSON。

新增地点核查包括事件发生地或项目覆盖区、提及医院、发布地、定位精度、原文段落依据、判断说明和审核人。精度可选国家、州/FCT、LGA、Ward、明确机构和待核查。该结果单独保存在 dios-location-文章编号，并随审核导出。

原始 DIOS 国家 Nigeria 与 NER 地点编码存在冲突线索，需要结合原文处理。地理精度不够时保留行政区范围。界面支持地点记录，没有把文章自动匹配到精确点。
