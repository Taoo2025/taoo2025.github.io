# FCT 上转路网计算

来源为 Geofabrik 官方 Nigeria OSM PBF，原始文件保存于 data/nigeria-routing.osm.pbf。道路数据版权 OpenStreetMap contributors，ODbL。处理日期 2026-11-10，文件校验值记录在计算结果中。

机构来源 HDX Nigeria Health Facilities。计算起点为 FCT 登记机构，目标为全部 FCT 中更高层级且接入成功的机构。先在区域有向图上求最短道路距离，然后排序前三家。

路网范围经度 6.2–8.3、纬度 8.0–10.2，包含 FCT 周边。按道路的节点连接，识别机动车通行标记及单行方向，包括反向单行和环岛默认方向。排除明确禁止机动车和私有通行的道路。保留道路类别 motorway、trunk、primary、secondary、tertiary、unclassified、residential、living_street、service 及对应 link。

医院连接最近的可行车路网节点，上限 500 米。节点接入间隙独立显示，未计入道路距离与时间。连接可能需要人工检查，尤其是双向分隔道路、围墙和医院入口。

估算速度 km/h：motorway 80、trunk 70、primary 60、secondary 50、tertiary 40、unclassified 30、residential 25、living_street 10、service 15。时间为最短距离路径各段按类别速度累加。没有使用实时交通、路面质量或限速标签。未处理转向限制关系、障碍节点、条件通行规则。区域边界可能限制可选路线。

网页加载预计算结果，选择转出机构后显示候选道路距离与假设时间，点击候选绘制实际道路几何。医院层级来自原始数据，临床服务和接诊能力仍需核实。
