# CareLink 提交候选版：使用与数据调整

版本：2026-11-11。目标是可访问、可操作、可继续复核的数据平台；临床接诊能力、部分位置与DIOS证据仍未确认，不声称数据核查全部完成。

## 两个入口

- 医院/行政区/道路转诊：https://taoo2025.github.io/carelink/?view=hospitals
- DIOS文章/地点复核：https://taoo2025.github.io/carelink/?view=signals

## 数据不写死在程序中

公开 `config.json` 配置医院、DIOS、地点核查、批次、边界、人口、路由和异常对比的文件地址。程序运行时读取这些JSON/gzip文件，地点/文章修正不必改JS记录常量。默认保持Nigeria/FCT试点；其他州可浏览机构，不能暗示同样具备路由索引。

顶部“数据调整与团队复核”是保留的数据入口。维护人员可以载入、编辑并应用源配置；也可恢复发布配置。高级数据源替换需保证文件结构、来源和同批版本匹配。

## 修改医院位置或行政字段

在医院页搜索名称/ID，点击医院，再展开调整窗口。原始坐标可对照；经纬度、名称、登记州/LGA与层级可编辑。每次保存必须提供来源/证据、审核人、原因；无效经纬度、未知ID或与基准不符的修正会被拒绝。原始HDX文件保留。

修改坐标后重新判断LGA；Ward需要独立确认。恢复单家发布值不会删除其他医院修正。修正记录留有before/after和时间，并随团队JSON导出。6家异常医院的比对与未确定假设见医院位置异常_核查说明.md和对应JSON；没有自动移动任何原始点。

## 路由和人口覆盖的版本保护

路由及人口结果保存医院ID、坐标、层级快照。坐标/层级/州改变，或新数据与结果快照不匹配时，旧道路路径和医院邻近覆盖暂停显示，提示重算。不能把新医院点套入旧路径。

道路模型仍是Geofabrik来源、已支持部分转向规则的有向最短道路距离；分钟数为限速约束下的速度假设估算。人口覆盖是唯一格网的直线5/10km邻近口径，不是行车等时圈。入口、条件转向、未知闸门、交通及接诊能力的限制保留。

重算脚本 `scripts/build_routes_v2.py` / `build_population.py` 已写入相同快照。重算后按config地址替换JSON/gzip文件；网页会重新校验。

## DIOS调整与团队复核

DIOS原文列表、地点初筛和批次清单均为运行时数据。已发布41篇批次有39篇可读、2篇原文受限；14篇高优先级和5组重复候选可筛选。逐篇表单保留发表日期/日期依据、事件地、医院提及、发布地、精度、证据、审核人和重复组。

可“导出当前DIOS数据模板”，编辑其中signals数组后导入。每条需唯一文章ID、标题、HTTP原文链接、国家、主题数组、位置数组与摘要。也可导入网页原有审核导出格式（history/locations）。病例确认仍需原文、人工审核人、当地病例用途与核实LGA，不因导入而放宽。

## 导出、共享、导入

“导出团队修改”生成JSON，包含医院修正/前后历史、本机DIOS地点审核和一般审核历史，以及自定义数据源配置。队友在同一窗口导入；先校验再应用，存储不足时回滚。恢复DIOS发布数据会保留已有逐篇审核。

GitHub Pages是静态网站：个人修正只保存在当前浏览器，不会自动回写GitHub或同步到队友。需要通过JSON共享，或经团队复核后将新的运行数据提交到GitHub。导出文件应保留来源，不含患者身份或推测病例坐标。

## 验证与来源

已验证医院搜索、原始位置展示、无效经度拒绝、保持原值的保存/恢复、DIOS批次读取；纯函数测试验证位置改变使旧快照失效、保留原始值、多边形孔洞、DIOS重复ID/非法URL拒绝。全部FCT路径与人口数据校验保留，生产构建通过。正式发布状态另记部署结果，不能把本地构建当上线。

运行数据仍来自组委会指定渠道：HDX、Geofabrik、WorldPop、PDP和DIOS；GRID3/GeoPortal提供核查图层。医院公开地址佐证保存在单独对比文件，不自动覆盖机构坐标或临床能力。
