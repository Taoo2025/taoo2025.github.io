# 转诊方案与人工复核流程

2026-11-11更新。医院页选择起点和上转道路候选，展开“转诊方案记录”，填写记录人、选择依据并可关联真实DIOS报道后保存。记录起终点坐标/层级、道路公里数、假设分钟、路网来源/哈希、接入间隙、报道审核快照及待核实事项。没有患者身份字段，不表示医院已联系、接收或患者转运完成。

方案状态：待团队复核、已复核方案、作废。状态变更要求审核人与依据，保留历史；方案医院或路网版本改变时标为历史待重评，不删除原始快照。方案可单独导出，也包含在团队JSON中导入导出；同ID不同内容的导入会拒绝，避免覆盖队友版本。

DIOS新增五种人工复核状态：待人工复核、背景保留、排除、需补证据、病例候选，可按状态筛选。完成复核必须填写人工审核人、说明与证据；修改依据会撤销原确认并重置待复核。病例候选不自动进入病例统计，仍需满足原文、区级定位与人工确认条件。保存前后值及时间，可导出审核历史。

从DIOS文章可前往医院页关联方案，但不自动将新闻发生地变成患者或转诊起点。浏览器本地保存，通过JSON共享；GitHub Pages不提供多人实时同步。数据更新后的自动重算尚未增加，仍按现有脚本执行。
