## 方法与证据边界

1. 只访问原导出URL，保留重定向、HTTP状态、正文/响应哈希和提取方法。部分此前已读取材料复用2026-11-11缓存，逐条注明，未冒充当日重新下载。初次连接失败者低并发重试；403/404、网络失败与200验证页均不当作可读正文。
2. 排除订阅弹窗、网站页脚和推荐内容对地点的干扰。主要段落对照标题与导出摘要；摘要不代替原文。匹配正文的原页发表元数据仅作发表日期，不自动填写事件日期。
3. 分开记录事件/项目范围、提及医院及发布地。没有依据的地点留空；国家级背景不强行下分到LGA，外州或外国个案不进入FCT统计。
4. 个案、手术计划、累计治疗量、历史调查、政策倡议和活动地点分别处理，不生成患者点、负担指数或临床服务能力。
5. 同文和同事件归组供人工核对；不把同主题、同医院或同人名一概合并为病例。
6. 公开文件仅保存来源、概述、段落定位和哈希；正文缓存留本地，不上传全文。既有50篇核查记录保留历史快照。
