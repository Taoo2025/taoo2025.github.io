方法：固定原始队列 → 访问原站 → 提取正文与发表元数据并排除推荐/页脚 → AI逐篇区分地点角色、主题、日期、重复关系 → 保留原文链接和访问审计 → 人工复核。新闻日期不当事件日，医疗机构提及不当能力验证。无法访问的两篇没有使用摘要代替原文。
