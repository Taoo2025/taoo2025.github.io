# 第 4、5、6 项实施记录

更新日期：2026-11-11。范围：Nigeria / Federal Capital Territory（FCT）。只使用组委会指定 HDX、Geofabrik、WorldPop、PDP、DIOS 渠道，以及已核实的 Africa GeoPortal / GRID3 公共图层。本文记录当前实现；旧文档段落作为历史记录保留。

## 4．行政区、DIOS、医院与转诊联动

**解决的问题：** 原来医院、新闻与路由分别展示，不能按医院实际落区联合查看。

**方法：** 读取既有 `fct_admin_checks.json` 的点落面结果，结合 `fct_lgas.geojson` 的 6 个 LGA 多边形。下拉选择或点击边界后，医院列表与地图同步筛选；选择医院后，仍以 FCT 全部更高层级机构为候选，允许跨 LGA 上转。原始 HDX LGA、坐标与冲突记录保留，不按新边界改写原始数据。576 条 FCT 登记中，572 条落在单一 FCT LGA，4 条在边界外；其中 2 条落区与原登记 LGA 不同，仍显示核查提示。

**DIOS 纳入规则：** 保存原文证据、事件地、医院提及地、发布地、精度、审核人、重复组。区级病例汇总要求：原文已读取、用途为当地病例、病例证据为真、人工确认、FCT 区域代码、核实 LGA，以及 LGA/Ward/明确机构精度。按重复组或文章 ID 去重。只有 FCT 级证据的项目报道只作为 FCT 背景列出，不下分至 LGA，不推断患者坐标。

**目前证据：** 既有 50 篇位置核查队列中，8 篇原文已读取、1 篇暂不可访问、41 篇待核查。8 篇中 5 篇符合当前 FCT 级项目背景展示条件。没有符合区级病例纳入条件的记录；网页显示 0，含义是尚无合格记录，不能理解为零病例。8 篇均为 AI 辅助核查，尚待团队复核。本次没有把其余 41 篇标成完成。

**交互与存储：** 背景条目可直接打开指定文章审核；人工保存后，同页事件通知及跨页 storage 事件刷新联合分析。记录仍存个人浏览器，可导出 JSON，不会上传 DIOS。审核后区级事件可返回对应 LGA 的医院列表，不自动启动患者转诊。

**验证：** 浏览器实测 Abaji 筛选后显示 47 家机构（46 Primary、1 Secondary）；FCT 的更高机构仍保留为路由候选。指定文章深链接可打开真实原文和已有核查。未确认区级地点的报道被表单阻止纳入病例统计，测试未写入虚构病例。

## 5．道路路由可靠性

**解决的问题：** 旧节点最短路只能处理道路单行，可能经过已标记的禁止转向或机动车障碍；压缩数据在本地服务器自动解压后又被网页二次解压。

**数据：** 组委会推荐的 Geofabrik Nigeria OSM PBF，原文件保存在 CASA 的 data/nigeria-routing.osm.pbf。链接 https://download.geofabrik.de/africa/nigeria-latest.osm.pbf 。保留 bbox=[6.2,8.0,8.3,10.2] 区域网络，允许路径离开 FCT；仅候选医院限定 FCT。

**方法：**
1. 按 motorcar → motor_vehicle → vehicle → access 的优先级判断机动车通行。读取机动车专用单行标签、普通单行和环岛方向。
2. 从路网移除明确禁止通行的节点与未明确允许机动车的 bollard、block 等障碍节点。未知闸门开放状态只计入审计，不冒充已核实。
3. 提取无条件、单一 via-node 的机动车 no_* / only_* 转向关系；在受限制路口建立“前驱节点、当前节点”状态，保留驶入方向，防止普通节点最短路绕过禁止转向。via-way、条件关系及其他不支持的关系单独计数。
4. 建立有向稀疏图，逐个高层级终点在反向图上做 Dijkstra，得到最短道路距离。重建路径时再次检查支持的转向规则，并按层级过滤、距离排序，显示前三个候选。
5. 分钟数按道路类别假设速度逐段相加；可解析的普通/方向性 maxspeed（含 mph）仅用来压低假设速度。没有实际交通速度或紧急车辆豁免假设。
6. 医院连接最近可行车普通节点，超过 500m 不生成候选。接入间隙以灰虚线显示，不计入道路距离或时间；真实医院入口、接入段可通行性仍未知。路径接近区域边缘则提示核查，不能据此保证全局最短。
7. 网页先识别响应是否仍是 gzip 字节，再决定是否解压；失败回退普通 JSON，兼容 Vite 和 GitHub Pages 的不同响应方式。

**复现：** `scripts/build_routes_v2.py`、`routing_rules.py`、`test_routing_rules.py`。测试包括反向单行、环岛、专用规则覆盖、access 优先级、障碍、mph 转换、禁转后最短路径必须绕行，以及 only/no-U-turn。规则测试通过；重算结果与路径审计见下方自动补充结果及 `public/data/routing_audit.json`。

**明确限制：** 并行同节点路段目前保留一条最短边，可能丢失原 way 身份；via-way/条件限制未求解；道路质量、封路、未知闸门、真实入口、实时交通和医院接收能力未知。这些限制已公开显示，不声称临床可执行或完整导航。

## 6．WorldPop 人口及不重复覆盖

**解决的问题：** 用真实人口分布解释医院周边空间覆盖，并避免多家医院缓冲区人口相加造成重复计算。

**来源与版本：** WorldPop Global2 R2025A v1，2025 年、constrained、UN-adjusted，30 arc-seconds（赤道约 1 km）。官方目录 https://hub.worldpop.org/geodata/listing?id=136 ，官方栅格 https://data.worldpop.org/GIS/Population/Global_2015_2030/R2025A/2025/NGA/v1/1km_ua/constrained/nga_pop_2025_CN_1km_R2025A_UA_v1.tif 。CC BY 4.0，WorldPop / University of Southampton。单位是每格估计人数，不是人口密度、患者数或孕产妇人数。

**方法：** 从官方全国栅格裁剪 FCT；有效非负格网按中心点分配给唯一 LGA，NoData 排除，零人口格保留，小数人数保留至展示。使用 EPSG:32632 计算格网中心至 572 家已落在 FCT 单一 LGA 的登记机构，以及其中 39 家 Secondary/Tertiary 机构的最近直线距离。每个格网对每项 5km/10km 阈值只计一次；另将每格人口仅归属最近一家机构，得到不重叠的机构空间分配人口。边界上的并列行政区按名称顺序唯一分配，并记录数量。本次无并列格网。

**统计结果：** 7,067 个有效格网，FCT 模型人口约 5,088,861 人。距任一登记机构直线 5km 内约 5,060,149 人（99.4%）；距二/三级机构直线 5km 内约 3,371,641 人（66.3%），10km 内约 4,659,003 人（91.6%）。显示总体、LGA 及所选机构分配人口，并可开关格网中心图层。

**验证：** 格网 ID 唯一；六个 LGA 之和等于总体；机构分配人口之和等于总体（浮点舍入容差 <1人）；5km ≤ 10km ≤ 总人口。真实格网和统计通过以上校验。

**限制：** 这是直线邻近覆盖，不是道路等时圈或实际就诊覆盖；与医院间道路路由分开解释。格网中心归区存在边界近似；没有按格网边界面积切分人数。人口2025、医院历史登记、边界2026的年份不同；模型估计不应当作人口普查实测。FCT 之外医院未计入最近机构分析，边缘覆盖可能偏低。

**文件：** `public/data/worldpop_fct_2025.tif`（原分辨率裁剪）、`worldpop_cells.json`（每格唯一记录）、`worldpop_summary.json`（来源/哈希/方法/总体/LGA/机构分配）、`scripts/build_population.py`。全国原文件保存在 CASA data/worldpop_nga_2025.tif，不在网页中重复加载。

## 最终重算与验证结果（2026-11-11）

路由重算成功：574 家机构在 500m 阈值内接入道路；566 家产生更高层级候选，共 1,698 条前三候选路径。8 家 Tertiary 没有更高层级目标，2 家超出接入阈值，不生成路径。

区域发现 17 条转向关系，其中 10 条无条件单一 via-node 关系已支持，涉及 8 个路口；7 条不支持关系仍需更完整导航引擎处理。227 个明确障碍/禁行节点被阻断，244 个相关道路段被排除。905 个区域闸门节点开放状态未经确认；计数不等于所有候选路径都经过闸门。

与旧版对比，80 家机构的候选或估算分钟发生改变。全部 1,698 条重建路径的支持转向规则均在计算过程中断言检查；独立一致性校验确认层级上转、前三排序、接入阈值、合法坐标及 gzip/JSON 内容一致。当前展示路径没有触发区域边缘提示，但这仍不能证明未受截断影响。

人口 7,067 个格网通过 ID 唯一、LGA 求和、机构分配求和与阈值单调校验。网页实测 Abaji 47 家机构、跨 LGA 高级机构候选、WorldPop 图层、文章深链接、证据不足禁止病例纳入，以及新版路网审计计数。选取 Oripisaka → Abaji General Hospital 可显示 2.437km 道路路径，起点接入 21.8m、终点 10.2m；4.1 分钟只是速度假设估算。

改用 pyosmium 原生标签筛选与原生节点位置缓存，避免为全国每个节点运行 Python 回调。本次完成重算耗时约 130 秒；不同设备耗时可不同。单行规则包括 motorway_link 的默认单行与专用标签覆盖。规则语义参考 [OSM turn restrictions](https://wiki.openstreetmap.org/wiki/Relation:restriction)、[motorway_link](https://wiki.openstreetmap.org/wiki/Tag:highway%3Dmotorway_link)；读取方式参考 [pyosmium handlers](https://docs.osmcode.org/pyosmium/latest/user_manual/05-Working-with-Handlers/)。

生产构建通过：React/Vite 静态产物位于 dist，使用 `/carelink/` 基路径，可用于 GitHub Pages。当前这轮修改保存在 CASA；本轮没有执行 GitHub 上传或更新线上链接，不将本地验证当作线上同步完成。没有生成新 ZIP。

审计文件：`public/data/routing_audit.json`、`docs/456验证结果.json`。完整一致性复核：`python scripts/validate_project.py --root "项目目录"`；与旧版差异统计需要旧结果基线，没有基线时该项输出 null，其余校验不受影响。
