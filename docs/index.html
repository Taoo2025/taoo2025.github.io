CASA0001

Urban Systems Theory · 城市系统理论

汽车出行与社会学理论 →

比较汽车依赖、城市空间结构和社会理论的关系。

人格、迁移与因果建模 →

借助因果图讨论人格特征、迁移行为与城市理论。

CASA0002

Urban Simulation · 城市模拟

伦敦地铁网络韧性与超市选址 →

通过网络失效模拟和空间交互模型，比较关键站点及 Havering 的候选超市位置。

CASA0006

Data Science for Spatial Systems · 空间系统数据科学

旅游空间因素能否改善 Airbnb 活跃度预测？ →

比较伦敦房源属性与旅游聚类特征，使用分类模型评估额外空间信息的预测价值。

CASA0007

Quantitative Methods · 定量方法

伦敦零售地理：The Great Homogenisation →

面向公众的数据叙事，比较 2015—2025 年伦敦零售结构与地区贫困水平。

零售地理研究：技术附录 →

完整的数据、统计方法、回归结果与验证说明。

CASA0011

Agent-Based Modelling · 多主体建模

Sugarscape 模型的系统实验 →

通过参数实验、Gini 系数和 Lorenz 曲线研究财富不平等的形成。

Airbnb 短租与租户迁移模拟 →

以房东、租户与空间环境为主体，探索短租压力和 90 天上限政策情景。

CASA0029

Urban Data Visualisation · 城市数据可视化

英国零售业态与便利店占比交互地图 →

个人作业：按品牌和地方行政区探索零售门店分布，结合图表与交互地图展示便利店占比。

伦敦公共交通可达性与线路中断 →

团队项目：完整交互叙事及地图，展示线路中断对可达性的影响。
