Individual Visualisation Assessment 1, Student Number: 25063842 Distribution of Retail Formats and Convenience Store Ratio Interactive Map 2025 Overview This visualisation project presents an interactive geospatial analysis of the retail landscape across the United Kingdom, focusing specifically on the spatial dichotomy between convenience stores and superstores(Lu et al., 2023). The study integrates high-resolution retailer point data from Geolytix with official Local Authority District (LAD) boundaries sourced from the UK government's Open Geography Portal. This visualization website facilitates data exploration and comprehension by presenting information through visual charts and interactive maps. Map data has been cropped to administrative districts. By employing varying saturation levels within a unified color palette, it clearly illustrates the distribution patterns of supermarkets and convenience stores operated by six UK retailers specializing in convenience store operations (Savills UK, 2025). The map supports viewing specific convenience store counts by area, switching to display convenience store distribution percentages across broader regions, and features interactive hover and click-to-freeze functions for comparative analysis(Gamlen, Goodwin and Ho, 2025). Figure 1: Distribution of Retail Formats map at Local Authority Scale Figure 2: Distribution of Convenience Store Ratio map at Local Authority Scale Technical Aspects: Mapbox and Data Scales Retailer data was cleaned using Python to identify all convenience store operators in London. Precise distribution counts were calculated by borough, followed by density calculations after merging areas.Map data underwent preprocessing in QGIS, linking store-level addresses with local authority boundaries. The interactive map was built with Mapbox, incorporating processed retailer and map data. The base map was designed in Mapbox Studio, with linear zooming applied to both point and polygon data for optimized visual experience. Hover interactions were implemented using Mapbox GL JS, incorporating an invisible overlay layer beneath the base map to detect hover events. The legend updates dynamically with each hover, and clicking locks the hover toggle for viewing. The retailer data is illustrated below: Cartographic AspectsRetail outlet data selects brand colors, such as Tesco's recognizable blue, with varying saturation levels to distinguish superstores from convenience stores, enhancing visual recognition. This design reflects the trend toward convenience store dominance in London's retail market. The color scheme originates from Gemini's recommendations and is implemented via Mapbox. The base map uses a gray-white palette to improve contrast with the map data. And the legend clearly labels data sources and defines the meaning of different data categories. Limitations and Improvements Establishing a time series would better illustrate how London's convenience store trend has evolved. Given the limited timeframe and data processing constraints of this project, future work could process a decade's worth of retailer location data to achieve a more comprehensive long-term visualization experience.
